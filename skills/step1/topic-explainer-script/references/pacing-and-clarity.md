# 节奏、注意力与易懂

一条 10 分钟左右的讲解，观众随时可以划走。本文件解决三个问题：**怎么切**（章节结构）、**怎么留**（节拍与注意力）、**怎么懂**（循序推进与易懂写法）。

长度和节拍的具体数字见 `SKILL.md` 的长度配置，本文只用“一章”“一个节拍”来指代。

## 一、章节结构

### 为什么要分章

edX 对 690 万次观看的研究发现，无论视频多长，中位观看时长都不超过约 6 分钟，研究者因此建议把内容切成 6 分钟以内的块。所以不要把 10 分钟当成一整块来写，而是写成 4-5 个前后相连、每个 2-3 分钟的章节。每一章都要让中途进来的观众能接住，也要让想走的观众有理由留下。

### 全片骨架（以 3500 字为例）

| 部分 | 位置 | 约字数 | 任务 |
|---|---|---|---|
| 开头 | 0-1 分钟 | 250-320 | 钩子 + 高调的价值承诺 + 一句话路线图（见 `hook-playbook.md`） |
| 第 1 章 | 约 1-3 分钟 | 600-750 | 最容易懂、最贴近观众的一层：现象和第一个解释 |
| 第 2 章 | 约 3-5 分钟 | 650-800 | 往下挖一层：原因或机制。约 3 分钟处放第一个大钩子 |
| 第 3 章 | 约 5-8 分钟 | 700-850 | **全片高潮**：最反常识、最有分量的发现，放在全片约三分之二的位置 |
| 第 4 章 | 约 8-10 分钟 | 600-750 | 落地：这对观众意味着什么，能怎么看、怎么做，边界在哪里 |
| 结尾 | 最后 30-45 秒 | 150-250 | 回扣开头的问题，给出变化后的答案，留下一个可讨论的判断 |

- 选题足够丰富时可以写 5 章，但每章不少于 `chapter_chars` 的下限，宁可少一章，不要每章都浅。
- **最好的内容放在约三分之二处，不放结尾。** 多数观众看不到最后；高潮放在三分之二处，既奖励留下来的人，也给后半段续命。
- 章节顺序 = 理解顺序：先现象后原因，先具体后抽象，先熟悉后陌生，先“是什么”再“为什么”最后“怎么办”。

### 每一章的内部结构

每章都是一个小视频，按这四步写：

1. **入口问题**（1-2 句）：这一章要回答的具体问题，最好是观众此刻心里正冒出来的那个。
2. **展开**：解释 + 例子 + 数据，每个节拍一次推进（见下文）。
3. **章内兑现**（1-2 句）：把这一章的问题答清楚，给出一句可以带走的结论。
4. **桥**（1-2 句）：一句话回顾“我们已经知道了什么”，再抛出下一章的问题。

不要在章内兑现之前就开始下一章的话题。也不要在一章里回答两个问题。

## 二、节拍：让注意力不掉

### 节拍规则

每个节拍（`beat_interval_chars`，约 1 分钟）内，至少出现下面一种**注意力手段**，相邻节拍不要用同一种：

| 手段 | 写法示例 |
|---|---|
| 替观众提问 | “听到这里可能有人会问：既然这样，为什么大家还要……？” |
| 具体例子或场景 | 一个人、一件事、一个画面，最好有时间、地点、动作 |
| 一个数字 + 翻译 | 数字之后立刻说“这意味着……”，把它换算成熟悉的东西 |
| 反转 | “但事情没有这么简单。”之后给出推翻上一个直觉的证据 |
| 类比 | 用日常经验解释抽象机制：“它就像……” |
| 对比 | 两种人、两个时代、两个选择并排放 |
| 小结论 | 一句短而有力的判断，可以单独被截图 |
| 预告 | 留一个开环：“这个现象还有一个更反直觉的原因，第三部分会讲到。” |

### 开环与闭环

- 全片同时开着的大悬念保持 2-3 个：开头的总问题、约 3 分钟处埋的一个、约 6 分钟处埋的一个。
- **每个开环都必须闭合**，并在 `_beat_sheet.json` 里记录在哪里开、在哪里闭。只开不闭，观众会觉得被骗。
- 章间桥是最重要的开环。研究和从业者经验都显示，转场处最容易掉人，所以每章结尾都要给出“为什么值得看下一章”。

### 重新抓住注意力的两个关键位置

- **约 3 分钟**（第 1 章结尾到第 2 章开头）：开头的新鲜感耗尽了。放一个强反转，或者抛出全片第二大的问题。
- **约 6-7 分钟**（第 3 章中段）：这是中位观看时长的边界。全片高潮就放在这里附近。

### 节奏的变化

- 句子长短交替；讲到关键结论时用短句，解释机制时可以稍长，但单句不超过 25 字。
- 信息密度有起伏：一段硬核解释之后，接一个轻松的例子或类比，让大脑喘口气。
- 不要连续两个节拍都在讲背景、定义或概念。

## 三、温和推进：让观众知道自己走到了哪里

信号原则（Mayer 多媒体学习研究）：用口头提示标出内容的组织结构，能帮助理解。但在短视频平台上，“第一点、第二点”的课堂腔会让人想划走。做法是**温和的进度提示**：

- **开头给一句话路线图**，只说要走的路，不剧透答案：“要搞懂这件事，得回答三个问题：它为什么会发生，为什么越来越严重，以及我们能做什么。”
- **章首用问题当路标**，不用序号：“那它为什么会越来越严重？”
- **章尾一句话回顾**，帮中途进来的人接上：“到这里我们知道了：累不是因为动得多，而是休息的方式错了。”
- **到了高潮之前给一个进度感**：“前面这些都是铺垫，真正反直觉的部分在这里。”
- **快结束时给收束信号**：“最后，回到开头那个问题。”
- 进度提示每章最多 2 处，不要每段都说“我们已经……”，否则节奏会拖。

## 四、易懂：只听一遍就能懂

观众是在听，不能回看，也不能停下来查资料。

- **一个段落只讲一个新东西。** 一个新概念讲清楚以后，再引入下一个。
- **先具体，后抽象。** 先给例子或现象，再说概念名称。
- **专业词第一次出现时用大白话解释**，后文始终用同一个词，不要来回换同义词。能不用术语就不用。
- **数字要翻译。** 每个数字后面跟一句“这相当于……”或“也就是说……”。一个句子最多一个数字，大数字取整。
- **口头列举不超过 3 项。** 超过 3 项时分组，或者只讲最重要的 3 个。
- **因果链一步一步讲。** 每一步一句话，用“所以”“于是”“结果”串起来，不要在一句话里嵌套两层因果。
- **重要的结论说两次**：先在讲解中说，再在章尾回顾中换个说法说一次。
- **预判误解。** 观众最可能误解的地方，主动点破：“这不是说……，而是说……”。
- **用“我们”带着观众走**，像一个懂行的朋友在讲；少用连续的“你要……你必须……”，避免说教。

## 五、画面平衡（流水线要求）

第 1.5 步会把正文切成很多段，每段配静态图（`image`）或动态信息图（`hf`）。外层要求两者比例在 3:7 到 7:3 之间。观众看配图视频时，画面长时间不变也会划走，所以正文要让每 30-50 字都有一个可以画出来的东西：

- **画面型句子**：具体的人、场景、动作、物件，适合配静态图。
- **逻辑型句子**：数字、对比、因果链、步骤，适合配动态图表。

两类交替出现，连续 3 句以上都是同一类时，换一句另一类的。

## 六、平台差异

以下是从业者共识和公开报道，不是官方规则。

| | 抖音 | 微信视频号 |
|---|---|---|
| 分发 | 兴趣推荐为主，面对陌生人 | 社交推荐占比高，朋友点赞会被好友看到 |
| 开头 | 更快、冲突感更强 | 同样要快，语气更稳，不要冒犯感 |
| 中长视频 | 节拍要密一些，反转多一些 | 可以多一点温度和完整的推理，结论要“点赞不丢人” |
| 驱动互动 | 评论区争议、收藏实用信息 | 转发给朋友、家人或群里的实用价值和共鸣 |
| 标题 | 带搜索关键词，信息完整 | 辨识度高，适合在朋友圈和群里转发 |

`platform` 为 `both` 时，开头快而稳，中段节拍按抖音的密度，结论按视频号的标准写。

## 七、结尾

- 回扣开头的问题，用走完全程后的新视角回答一遍，并回扣开头许下的那个大格局。
- 给观众一个可以带走的东西：一个判断、一个方法，或一个看问题的新角度，对应 `_topic_brief.json` 的 `takeaway`。
- 把它收成一句**传播锚点**：短、能单独截图或转述、离开视频也成立，比如三步方法、一个新定义、一个反常识判断。它是内容本身，不是请人转发。
- 留一个真实的、可讨论的判断，让人想在评论区表态或补充经验。
- 不写运营话术：“评论区告诉我”“你怎么看”“点赞关注”“学到了扣1”“转发给需要的人”。
- 不写课程式总结：“总的来说”“综上所述”“希望对你有帮助”。

## 八、配音写法

- 用逗号和句号控制停顿，标点不足会显得急促。
- `%` 写作“百分之”，`~` 写作“到”，`/` 写作“每”或“或”，`vs` 写作“对比”；英文缩写首次出现时用中文说明。
- 日期、金额、比例写成口语可读的形式，不写“12/04”“1.2M”。
- 避开容易读错的多音字组合，必要时换同义词。
- 不用括号、长插入语和舞台说明，正文只放要念出来的话。
- edX 研究发现，语速偏快、有热情的讲解更吸引人，所以不要为了“讲清楚”而把句子写得拖沓。

## 九、文风与禁用表达

- 简体中文，口语化，像一个懂行的朋友在认真讲一件值得知道的事。
- 敢下判断，但每个判断都有调研支撑；有争议的地方说明边界。
- 不煽情，不堆形容词，用细节和事实制造情绪。
- 不编造第一人称亲身经历。

全文禁止：“接下来我们来看”“下面我来介绍”“首先……其次……最后”“第一点……第二点”“值得注意的是”“不难发现”“这告诉我们”“这给我们的启示是”“总的来说”“综上所述”“希望对你有帮助”，以及第七节列出的运营话术。
