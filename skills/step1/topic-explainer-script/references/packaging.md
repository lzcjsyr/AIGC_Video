# 标题、封面与风险自检

终稿定下之后再写包装。标题、封面、金句的承诺都从终稿里来，不许超出正文。字数和条数以 `output-contract.md` 的 JSON 契约为准，校验脚本会检查。

## 三件套的分工

| 字段 | 字数 | 任务 |
|---|---|---|
| `cover_titles` | ≤10 | 大字报，印在封面上，一眼读完；只放一个视觉锚点 |
| `cover_subtitles` | ≤15 | 补充主标题或抛一个悬念，不重复主标题的字面 |
| `video_titles` | 15-30 | 信息完整，含搜索关键词；前 7 个字内要有钩子 |

`platform` 为 `channels` 或 `both` 时，标题尽量 ≤22 字，关键词往前放。

## 标题公式

3 条 `video_titles` 至少用 3 种不同公式，3 条封面主标题也尽量各用一种。一条标题最多叠 2 个公式。示例都以“为什么越休息越累”演示，示例里的数字只是占位，实际数字必须来自调研笔记。

| 公式 | 模板 | 示例 |
|---|---|---|
| 反常识断言 | 原来 X 不是 Y，而是 Z | 越休息越累，问题不在睡得少 |
| 清晰提问 | 为什么 X？（问题具体、重要、有意外感） | 什么都没干，为什么人却累得要命 |
| 数字 + 收益 | N 个 X，让你 Y | 疲劳分 3 种，歇错了越歇越累 |
| 点名身份 | 具体人群 + 处境或收益 | 久坐上班族，周末别再这样歇了 |
| 对比反差 | 同样 X，为什么差距这么大 | 同样睡够 8 小时，有人越睡越累 |
| 结果前置 | 先给结论，过程留着 | 让人恢复精力的，往往不是睡觉 |
| 高格局钥匙 | 看懂 X，就看懂了 Y | 看懂疲劳，就看懂了现代人的精力账 |
| 权威纵深 | 真实的学者、研究或年代 + 问题 | 科学家追了一百多年的问题：人为什么会累 |
| 避坑提醒 | 别再 X / X 的坑 | 刷手机不算休息，很多人都歇错了 |
| 金句钉子 | 一句判断直接当标题，适合封面 | 躺平不是休息 |

“权威纵深”里的人物、年代、研究必须查得到。不用“做了十年某某才敢说”这类需要编造身份或亲身经历的公式。

## 加分细节

- 数字要具体，不写“很多”“一大截”；能用精确数字就不用约数。
- 多用疑问句和逗号停顿：“30 岁，才想明白这件事”。
- 一条标题最多一个强情绪词，不堆“太”“真的”“绝了”。
- 不用行业黑话：“赋能”“抓手”“闭环”“底层逻辑”。
- 封面只留一个视觉锚点：一个词、一个数字或一个反差，不塞两个观点。

## 风险自检（P3）

逐条检查 `video_titles`、`cover_titles`、`cover_subtitles`、`golden_quotes`，命中就换说法。这里比正文更严：正文 L2 可以下主观的高评价，包装里不写绝对化用语。

| 类别 | 例子 | 怎么改 |
|---|---|---|
| 绝对化用语 | 最、第一、唯一、顶级、极致、绝对、100%、永远、终极 | 关键、绕不开、少有、显著、目前 |
| 疲劳的噱头词 | 震惊、惊呆了、不看后悔、万万没想到、刷爆、全网都在 | 删掉，用具体的事实制造反差 |
| 揭秘、揭黑 | 揭秘、内幕、不为人知的真相 | 改成具体问题 |
| 贩卖焦虑 | 再不 X 就完了、这辈子没救了 | 可以有紧迫感，不贩卖绝望：“再过几年，差距会更明显” |
| 虚假承诺 | 三天学会、稳赚、零风险、根治 | 用范围和条件说话 |
| 群体标签 | 某地人都、女人就是、程序员都 | 改成具体场景、具体的人 |
| 诱导互动 | 转发给、一定要看到最后、点赞再看 | 删掉，靠内容本身 |
| 品牌负面 | 点名某品牌的负面结论 | 改成“某品牌”“一家头部企业”，或只讲事实 |
