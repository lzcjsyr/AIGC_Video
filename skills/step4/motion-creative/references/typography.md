# 字体与阅读层级

中文使用本机 PingFang SC、Noto Sans SC 或本地打包的字体。不要从网络临时下载字体。
以 2560×1440 为参考：主关键词至少 200px，辅助短语至少 72px，核心数字至少 320px。其他画布按比例缩放。
主字至少为辅助字的 1.8 倍；信息文字透明度至少 0.78，标签至少 0.62。低于 0.4 的透明度只用于装饰。
中文字重选择 600–900，取决于已安装字体。无需英文装饰标签。字面尽量短，行高至少 1.1，给笔画留出空间。
动画文字避免同时套 CSS 初始 transform 和 GSAP x/y/scale；初始状态用 fromTo 明确声明。
展示关键词而非整段旁白。用截图确认字形完整、与背景对比清晰、底部字幕区没有正文。
